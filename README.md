# Sistema de Gestão de Pedidos (Order Management API)

Este projeto é uma API RESTful para gestão de pedidos, clientes e produtos. Ele foi desenhado para demonstrar habilidades em **Engenharia de Software**, Arquitetura de Banco de Dados e Qualidade de Código (TDD/BDD).

Escopo e Regras de Negócio
O sistema permite o cadastro de clientes e produtos, além da realização de pedidos que contêm múltiplos itens. A API calcula automaticamente o subtotal dos itens e o valor total do pedido.

# Tecnologias Utilizadas
* **Linguagem:** Java 21+
* **Framework:** Spring Boot
* **Banco de Dados:** PostgreSQL (Modelagem Relacional)
* **Testes:** JUnit, Mockito, Cucumber (TDD e BDD)
* **Documentação/Design:** UML (Diagramas de Classe e Casos de Uso)

## 📁 Estrutura do Projeto
* `/docs`: Contém os diagramas UML e documentação de requisitos.
* `/database`: Scripts SQL (DDL, DML) para criação e população do banco.
* `/src` *(em breve)*: Código-fonte da aplicação Java.
